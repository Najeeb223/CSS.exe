Legend - CSS Units

CSS units define the size and spacing of elements on the screen.

They tell the browser how much space to use — and relative to what.

Some units are fixed, like px. Others are flexible, like % or rem.

Understanding units is key to building responsive, scalable layouts.

Master them here. Equip the right one for every mission.

%

% is a relative unit based on the parent element’s dimensions. Use it to size containers, position elements, or fill bars based on dynamic proportions.

em

em sizes are relative to their parent’s font size. If a parent is 12px, then 1em = 12px and 2em = 24px. Nested em values multiply, so they can grow fast.

This font-size is 8px.
This font-size is 2em (2 x 8)= 16px
This font-size is 2em again (2 x 16)= 32px

rem

rem sizes are relative to the root element’s font size, not their parent. If the root is 10px, then 1rem = 10px and 2rem = 20px anywhere on the page. rem is consistent, no matter where it’s used.

ch

ch is based on the width of the character "0" in the current font. 1ch = the width of one "0", 10ch = ten zeros wide. It’s great for sizing inputs and aligning type.

This text is 40ch wide. The same text has more room

vh

Viewport height (vh) is generally used to set the height of layouts or elements by controlling what percentage of the visible screen they take up, the below example showcases 10vh and 20vh.

vw

vw stands for viewport width, 1vw equals 1% of the browser window's width, making it useful for responsive layouts that scale with the screen size.

vmin

vmin is a relative unit that equals 1% of the smaller value between the viewport’s width and height, making it useful for responsive designs that adapt to limited screen dimensions, with the below examples showcasing a sword with widths of 5vmin and 10vmin respectively.

vmax

vmax is a relative unit that equals 1% of the larger value between the viewport’s width and height, making it ideal for scaling elements on spacious screens, with the below examples showcasing a treasure chest with widths of 2vmax and 8vmax respectively.

CSS Grid is a two-dimensional layout system.

It allows precise alignment of elements into rows and columns.

display: grid activates the grid layout on a container.

grid-template-columns defines how many columns and their widths.

grid-template-rows sets the height and number of rows.

gap controls the spacing between grid items.

To position items, use grid-column and grid-row.

With just these properties, you can build responsive, organized layouts efficiently.



Groundbot's Orbital Laser

grid-template-columns defines the number of columns and how wide each should be.

Use fractional units like fr to divide space proportionally.

For example: grid-template-columns: 70px 1fr means a fixed first column and a flexible second column.

Knight's Emperor Swing

place-items is a shorthand for aligning grid items both vertically and horizontally.

justify-items controls horizontal alignment of items in their grid cells.

align-items controls vertical alignment within the grid cells.

Use place-content to align the *entire grid* inside the container.

Grid makes centering content effortless with these properties.

Dragon's Fireball

grid-area lets you name areas and place items by name instead of numbers.

grid-template-areas defines layout using text-based labels for each section.

These two properties make your grid more readable and maintainable.

Use repeat() to simplify patterns like equal-width columns: repeat(3, 1fr).

Use minmax() to create flexible sizes: minmax(200px, 1fr).

auto-fill and auto-fit help create responsive grids by automatically filling space with columns or rows.

justify-content and align-content control grid alignment within the container.

justify-items and align-items control alignment of items inside their grid cells.

Mastering these makes your layouts both flexible and precise.

Flexbox is a one-dimensional layout system.

It helps align items along a single axis — either horizontal or vertical.

display: flex turns a container into a flex context.

flex-direction sets the axis direction (row or column).

justify-content aligns items along the main axis (left to right by default).

align-items aligns items along the cross axis (top to bottom by default).

Use gap to add space between items.

Mastering these core properties gives you fast, responsive layouts with minimal code.

Flexbox basics recap: One-dimensional layout controlling a single axis.

flex-wrap lets items wrap to the next line instead of shrinking.

flex-grow makes items expand to fill available space.

flex-shrink controls how items shrink when space is tight.

flex-basis sets the default size before growing or shrinking.

align-self lets individual items override cross-axis alignment.

Using flex shorthand: flex: grow shrink basis;

Master these and you can create flexible, adaptive layouts without complex CSS.
